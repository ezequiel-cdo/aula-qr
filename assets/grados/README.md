# Emblemas EPJA por grado

Esta carpeta recibe **exclusivamente los cinco PNG originales** facilitados por el centro:

- `1erGrado.png`
- `2doGrado.png`
- `3erGrado.png`
- `4toGrado.png`
- `5toGrado.png`

Las imágenes se presentan como oferta institucional en `prepara-canastica/index.html`, sin enlaces a las aulas. También se muestran en las portadas de cada año. Para iniciar una sesión, el participante debe entrar mediante el formulario de identificación desde la portada institucional.

No subir aquí listados de estudiantes, datos de contacto ni archivos del Registro Maestro.
