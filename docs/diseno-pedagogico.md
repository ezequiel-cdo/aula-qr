# Diseño pedagógico de AulaQR

**Problema detonante:** tener una percepción de seguridad sobre nuestras contraseñas no implica poder justificar prácticas seguras.

**Reto:** pasar de «creo que mi contraseña es segura» a «puedo justificar por qué una práctica es más segura».

**Resultado esperado:** aplicar criterios básicos de seguridad para analizar y mejorar prácticas relacionadas con creación y uso de contraseñas, tomando decisiones responsables.

**Secuencia:** situación problemática → saberes previos → comprensión → procesamiento → aplicación → evidencia → evaluación → retroalimentación → reflexión → transferencia.

**Acciones cognitivas:** comparar, analizar, relacionar, decidir, aplicar, justificar y reflexionar. El participante es protagonista; el facilitador diseña, orienta, observa y retroalimenta sin sustituir su autonomía.

**Saber:** longitud, imprevisibilidad, unicidad, privacidad, gestores de contraseñas y MFA.

**Saber hacer:** analizar casos, identificar riesgos, comparar prácticas y justificar recomendaciones.

**Saber ser:** responsabilidad, prudencia, autonomía, colaboración y mejora.
