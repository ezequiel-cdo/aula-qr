2. Propiedades: las reglas que luego usarás con letras

Estas propiedades permiten reorganizar y transformar expresiones sin cambiar su valor.

Justificar

Conmutativa

a + b = b + a    |    a·b = b·a

No vale, en general, para resta ni división.

Asociativa

(a + b) + c = a + (b + c)
(a·b)·c = a·(b·c)

No vale, en general, para resta ni división.

Elemento neutro

a + 0 = a    |    a·1 = a

0 es neutro de la suma y 1 de la multiplicación.

Distributiva

a(b + c) = ab + ac

Es una de las puertas directas hacia el Álgebra.

Atención: cambiar el orden o agrupar “porque sí” puede alterar el resultado. Por ejemplo, 12 − (7 − 2) ≠ (12 − 7) − 2.

Práctica rápida

¿Qué propiedad explica 7(10 + 3) = 7·10 + 7·3?

3. Leyes de los signos: separar suma de producto

La regla depende de la operación. No uses la tabla de signos de multiplicación para sumar.

Decidir signo

Suma y resta de enteros

Mismo signo: suma los valores absolutos y conserva el signo.

−4 + (−6) = −10

Signos distintos: resta los valores absolutos y conserva el signo del número con mayor valor absoluto.

−9 + 5 = −4

4. Racionales y fracciones: operar sin perder el significado

Una fracción representa un número. Para sumar necesitas expresar las partes con el mismo tamaño.

Equivalencia

Suma y resta

a/b + c/d = (ad + bc)/bd

Si los denominadores son iguales, solo se suman o restan numeradores.

Producto y cociente

a/b · c/d = ac/bd
a/b ÷ c/d = a/b · d/c

En una división, el segundo número no puede ser 0.

5. Potencias: comprimir multiplicaciones repetidas

Las leyes dependen de tener la misma base o el mismo exponente; identifica la estructura antes de aplicar una regla.

Estructura
am · an = am+n
Producto de potencias de igual base
2³·2⁴ = 2⁷
am / an = am−n
Cociente, con a ≠ 0
5⁶/5² = 5⁴
(am)n = amn
Potencia de una potencia
(3²)⁴ = 3⁸
(ab)n = anbn
Potencia de un producto
(2·5)³ = 2³·5³
a⁰ = 1 y a−n = 1/an
Siempre que a ≠ 0
2⁻³ = 1/8
No existe una ley que diga am + an = am+n. La suma no se transforma así.

Práctica rápida

Simplifica x⁴ · x³.

6. Raíces: la operación inversa de elevar

√a representa la raíz cuadrada principal: el número no negativo cuyo cuadrado es a.

Invertir potencia

Idea fundamental

√49 = 7 porque 7² = 49

En los números reales, √a exige a ≥ 0.

Propiedades útiles

√(ab) = √a·√b
√(a/b) = √a/√b

Para raíces cuadradas reales, se usan con radicandos adecuados y denominador distinto de 0.

Error frecuente: √(a + b) no es, en general, √a + √b. Ejemplo: √(9+16)=5, pero √9+√16=7.

Explorador de raíces cuadradas

Busca si contiene un cuadrado perfecto y simplifica cuando sea posible.
